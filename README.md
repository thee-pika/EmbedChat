# 🚀 EmbedChat

EmbedChat is a plug-and-play AI chatbot that can be added to any website using a single script tag. It helps businesses provide instant customer support with minimal setup.

---

## ✨ Features

- ⚡ **Plug & Play** – Add chatbot with one script
- 🎨 **Customizable** – Adapt to your brand and behavior
- 💬 **Real-time Responses** – Instant AI-powered replies
- 🔗 **Embeddable Anywhere** – Works on any website

## ⚙️ How it Works

1. Copy the embed script from dashboard  
2. Paste it before `</body>` in your website  
3. Chatbot appears instantly
